TBDub open-source inference release

This distribution contains software derived from X-Dub and DiffSynth-Studio.
The original X-Dub project is available at:
https://github.com/KlingAIResearch/X-Dub

The TBDub release modifies the original inference pipeline, public command-line
interface, project naming, path handling, preprocessing wrapper, documentation,
and repository layout. Internal data-processing, batch, evaluation, and cluster
scripts are not included.

This distribution also includes a minimal DWPose inference wrapper and model
configuration files. Individual third-party components remain subject to their
respective notices and license terms.
